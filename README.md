# 混铁车中夜班安全检查报告生成工具 v1.0.1

根据“值班表”和“事故隐患排查整改登记表”，批量生成混铁车事业部中夜班（双休日、节假日）安全消防检查情况 Word 报告。

## 使用方法

- 拖入或选择值班表（.xls / .xlsx）与隐患登记表（.xlsx）
- 自动读取值班领导、作业区值班员，生成时自动填入姓名与职务
- 隐患项目列表支持 **Ctrl+A 全选**、Ctrl/Shift+单击多选，可对选中项批量设置/清空日期
- 选中项目后点击 **“生成选中报告文件”**，只生成选中项；未选中时会提示先选择
- 自动按登记表中的排查日期提取日期，也可按日期范围顺序循环分配
- 自动提取登记表中的“整改前/整改后”图片并写入报告
- 检查时间自动生成：周六/周日为 9:00–10:00，周一至周五为 15:00–17:00，具体时间随机
- 责任人直接填写当天值班领导
- 输出文件命名：`中夜班（月.日）安全消防检查情况(混铁车事业部).docx`

## 数据要求

### 值班表

表头需包含：`时间/日期`、`星期`、`值班领导`、`作业区值班员`（兼容炼铁的原料分厂/煤库/供矿多列格式）。

### 隐患登记表

表头需包含：`序号`、`事故隐患排查时间`、`隐患发现人`、`隐患地点`、`隐患项目内容`、`整改要求及期限`、`整改部门及负责人`、`整改结果`、`验收人`、`整改前`、`整改后`。
